# Exemplos experimentais de grupo

`group_integration_001.json` foi gerado com a configuração
`examples/experimental_group_config.json`, semente 51 e as fontes do commit
`2e5ec28`. Os 49 hashes de fontes e entradas registrados foram comparados com
esse commit. SHA-256 do arquivo:
`d13981d76af230b7f8ed8de4cbc351d481520841d9082f703c95c92e1de9bf33`.

O arquivo contém uma trilha integral, não um estudo estatístico ou uma
certificação do grupo. Os oponentes são sintéticos. A execução e as limitações
estão descritas em [GROUP_CHARACTER_EXPERIMENT.md](../GROUP_CHARACTER_EXPERIMENT.md).
Para gerar outro exemplo, use um nome novo; não substitua este arquivo.

`group_v2_integration_001.json` usa a mesma configuração e semente com o
contrato experimental v2 e as fontes do commit `905ad6e`. Os 50 hashes de
fontes e entradas foram comparados com esse commit; a reprodução em um processo
novo gerou bytes idênticos. SHA-256 do arquivo:
`c85d243068a37054749dbe61ea7fc168e794d7daa7fb368cbbba8c9b4e411d75`.
É um exemplo com adversários sintéticos, não uma conclusão de eficácia.

`group_grid_integration_001.json` usa o exemplo de grade, semente 51 e as
fontes do commit `d81101a`. Os 52 hashes de fontes e entradas foram comparados
com esse commit; uma execução nova reproduziu os bytes do arquivo. SHA-256:
`c889528502cf5447a3f9f018a1b8c82fec5496f3d2660ef50552dbe6c09a7127`.
As restrições de visão, ocupação e movimento estão em
[GROUP_GRID_EXPERIMENT.md](../GROUP_GRID_EXPERIMENT.md). Os adversários são
sintéticos e o resultado é apenas uma demonstração experimental.
